# CHECK Data

Отдельное хранилище каталогов для приложения CHECK.

Репозиторий содержит только данные профессий. Код приложения находится в `getto-dev/check`.

## Структура

```text
check-data/
├── index.json
├── schema/
│   └── dataset.schema.json
└── <profile>/
    ├── manifest.json
    ├── catalog.json
    ├── categories.json
    ├── search-synonyms.json
    └── config.json
```

`index.json` — маленький список доступных профилей. Сам каталог загружается только для выбранного профиля и далее может храниться локально в приложении.

Каждый профиль имеет собственную версию. Обновление каталога не требует выпуска новой версии приложения CHECK.

Текущий профиль `plumbing` находится в процессе переноса из старого встроенного каталога приложения.
