# CHECK Data

Данные для универсального приложения CHECK.

Репозиторий отделён от `getto-dev/check`: приложение содержит только общий движок, а каталоги профессий загружаются отдельно и могут обновляться независимо от версии приложения.

## Структура

```text
check-data/
├── index.json
├── plumbing/
│   └── manifest.json
└── README.md
```

Каждый профиль профессии в будущем будет содержать собственный каталог, категории, поисковые синонимы и настройки.

### Принцип

1. `index.json` — небольшой список доступных профилей.
2. `manifest.json` профиля — версия и пути к его данным.
3. Большие каталоги не вшиваются в приложение CHECK.
4. После загрузки выбранный профиль хранится локально и используется offline-first.
