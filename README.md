# CHECK Data

Отдельное хранилище каталогов для приложения CHECK.

Репозиторий содержит только данные профилей. Код приложения находится в `getto-dev/check`.

## Структура

```text
check-data/
├── index.json
├── schema/
│   └── dataset.schema.json
├── scripts/
│   └── validate-dataset.mjs
└── <profile>/
    ├── manifest.json
    ├── catalog.json
    ├── categories.json
    ├── search-synonyms.json
    └── config.json
```

`index.json` — маленький список доступных профилей. Сам каталог загружается только для выбранного профиля и после первой загрузки хранится локально в приложении.

Каждый профиль имеет собственную версию. Обновление каталога не требует выпуска новой версии приложения CHECK.

Текущий профиль `plumbing` содержит 271 позицию и уже используется приложением CHECK через удалённый dataset.

Перед публикацией изменений GitHub Actions автоматически проверяет JSON, версии, количество позиций, уникальность ID и соответствие категорий.
